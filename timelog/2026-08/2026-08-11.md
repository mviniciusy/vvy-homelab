## Tarefa 1: Auditoria de backups + correção de bug no backup_proxmox_config.sh

### Contexto

O usuário pediu uma análise geral dos backups do servidor vvy. Durante a
verificação, foi identificado um bug no `backup_proxmox_config.sh` que
impedia o upload das configs do Proxmox para o Google Drive desde 09/08.

**Erro encontrado no log:**

```
/root/scripts/backup/backup_proxmox_config.sh: line 154: LOG: unbound variable
[2026-08-10 02:00:02] Backup ENCERRADO COM ERRO (exit code: 1)
[2026-08-10 02:00:07] ERRO: Falha no upload rclone para gdrive:1. vvy/vvy-server-backup/Proxmox-Config/
[2026-08-10 02:00:07] Backup ENCERRADO COM ERRO (exit code: 5)
```

### Diagnóstico

O script `backup_proxmox_config.sh` (185 linhas) define a variável
`LOGFILE` na linha 43, mas as linhas 154 e 175 referenciavam `$LOG`
(variável inexistente). Com `set -euo pipefail` ativo, o script abortava
com "unbound variable" antes de completar o upload via rclone no CT 105.

### Correção

- **Arquivo:** `/root/scripts/backup/backup_proxmox_config.sh` (host vvy)
- **Comando:** `sed -i 's/tee -a "\$LOG"/tee -a "\$LOGFILE"/g'`
- **Linhas afetadas:** 154 e 175
- **Validação:**
  - `bash -n` (sintaxe) OK
  - Reexecução manual: `bash /root/scripts/backup/backup_proxmox_config.sh`
  - Resultado: tar de 24K criado, copiado para o storage, upload para
    Google Drive concluído (4.2s), retention local e remota aplicadas
  - Log confirmou: `Backup concluido com sucesso`

### Licoes

1. **Verificar logs antigos antes de reportar:** o erro do
   backup_proxmox_config.sh estava visivel desde 09/08, mas so foi
   detectado porque o usuario pediu auditoria completa. Logs de backup
   devem ser checados rotineiramente, nao apenas quando algo quebra.

2. **Variavel inexistente com set -u aborta silenciosamente:** o
   `set -euo pipefail` e uma protecao util, mas quando uma variavel
   errada e usada em um `if ! ... | tee -a "$LOG"`, o aborto acontece
   dentro da condicao do if, e o `exit 5` subsequente mascara o erro
   real (unbound variable) como "falha no upload rclone". Sempre validar
   nomes de variaveis apos refatorar scripts com set -u.
