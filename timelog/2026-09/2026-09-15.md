## Servidor dedicado Project Zomboid na VM Oracle (B42.20.4, ARM via FEX-Emu)

**O que foi feito**
- Instalado servidor Project Zomboid Dedicated Server Build 42.20.4 na VM Oracle (Arm Ampere).
- Caminho final: container Docker `etheth888/project-zomboid-arm64` (FEX-Emu embutido), com binarios x86_64 obtidos via SteamCMD logado no PC (o app dedicado 380870 nao baixa mais anonimo) e transferidos por rsync vvy -> VM via Tailscale.
- Recursos: `--cpus 4 --memory 16g`, heap JVM `-Xmx12g`, servidor `pzvvy`, mundo gerado e funcional.
- Fix critico aplicado: `ProjectZomboid64.json` ZGC -> G1GC + flags de reflection (ZGC nao emula em x86->Arm, causava SIGILL no boot).
- Portas liberadas em 3 camadas: Security List da VCN (via OCI CLI com API key), iptables interno (antes do REJECT, persistido), docker publish. UDP 16261-16262 + 8766-8767, TCP 16262-16272 (1 por slot).
- OCI CLI configurado na VM (venv /opt/oci-venv) — gestao do console por API (regras de firewall lidas/gravadas sem browser).
- Servidor online e respondingendo handshake UDP; pendencia final: GSLT token (conta que possui o jogo) para multiplayer Steam B42 sem travar em "obtendo informacoes".
