## Contexto

O servidor vvy (Proxmox VE, <HOST_IP>) apresenta hard freezes intermitentes desde 14/Jul/2026. O kernel congela completamente — sem SSH, sem logs, sem panic, sem OOM. A única saída é reboot manual ou via hardware watchdog (iTCO_wdt).

- GPU: Nenhuma (servidor headless)

## Diagnóstico

### Dois problemas independentes identificados

**1. MCE de memória (21/Jul, boots -3 e -2)**

- 105 CE (Correctable Errors) no Dimm6 (Micron 16GB), channel 3, slot 0
- Páginas de memória repetidas: 0x1a379, 0x1b4ec, 0x1a37d, 0x66741b
- Causa: mau contato ao recolocar as RAMs após limpeza física do servidor
- Status: Resolvido. Zero MCE nos boots -1 e 0 (atual)

**2. Hard freeze sem causa nos logs (desde 14/Jul, 7 crashes)**

- Kernel congela sem logar absolutamente nada (sem panic, sem OOM, sem MCE, sem UE)
- Última entrada no journal é sempre um processo normal (CRON, tailscale, etc.)
- O hard watchdog (iTCO_wdt) reinicia o servidor em ~60s, mas não captura o motivo

### Hipótese principal: C-states do CPU

- Plataforma Xeon E5 v2 / Ivy Bridge EP (chipset HM70, ~2013)
- No boot -9 (14/Jul) o GRUB cmdline tinha `intel_idle.max_cstate=1` — mitigation para freezes em CPUs Intel antigas
- Este parametro foi removido em algum momento apos 14/Jul
- CPUs Intel antigos tem bugs conhecidos onde C-states profundos causam hard freeze sem logs

## Mudança Aplicada

### Re-adicao de `intel_idle.max_cstate=1` no GRUB

- **Data:** 22/Jul/2026, ~14:55 BRT
- **Motivacao:** Mitigar hard freezes sem causa nos logs. CPUs Intel Ivy Bridge EP tem bugs conhecidos em C-states profundos que congelam o processador sem gerar nenhuma mensagem de kernel
- **Arquivo editado:** `/etc/default/grub`
- **Comando:** `sed` para adicionar `intel_idle.max_cstate=1` antes de `nmi_watchdog=0`
- **Pos-edicao:** `update-grub` executado com sucesso
- **Aplicacao:** Efetiva a partir do proximo boot. O cmdline atual ainda nao tem o parametro pois o servidor nao foi reiniciado desde a edicao

#### Antes

```
GRUB_CMDLINE_LINUX_DEFAULT="quiet intel_iommu=on iommu=pt pcie_acs_override=downstream,multifunction video=efifb:off nmi_watchdog=0"
```

#### Depois

```
GRUB_CMDLINE_LINUX_DEFAULT="quiet intel_iommu=on iommu=pt pcie_acs_override=downstream,multifunction video=efifb:off intel_idle.max_cstate=1 nmi_watchdog=0"
```

### Para reverter

```bash
sed -i 's/ intel_idle.max_cstate=1//' /etc/default/grub
update-grub
```
